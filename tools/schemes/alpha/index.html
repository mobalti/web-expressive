Embed code

Embed the code in the <head> of your HTML. 

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/web-expressive@1.0.0/dist/schemes/alpha/berry-tonal.css" />
<style>
@import url('https://cdn.jsdelivr.net/npm/web-expressive@1.0.0/dist/schemes/alpha/berry-tonal.css');
</style>

Example usage

.card {
    background: var(--sys-color-primary-container);
    color: var(--sys-color-on-primary-container);
}

Via npm

npm install web-expressive

Import the scheme into your global stylesheet

@import "web-expressive/schemes/alpha/berry-tonal.css";
