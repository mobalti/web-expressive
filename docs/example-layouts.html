Web Expressive: Example Layouts

Example layouts are design starters made by Material Design. They are meant to be a starting point rather than a final destination. Web Expressive provides an implementation for these starters as standalone HTML files that you can easily download, customize, or feed directly into AI coding assistants.

Why Example Layouts?

Web Expressive provides these starters to accelerate product development and optimize building in agentic workflows:

  • Example layouts are built using Web Expressive: They demonstrate how to implement real-world designs by composing the library's design tokens and components into custom patterns that follow Material Design 3 guidelines.
  • Example layouts are optimized for agentic workflows: Their standalone HTML files give AI agents concrete examples to inspect and adapt. These examples use modern CSS, semantic HTML, progressive enhancement, and native browser features, including <dialog>, the Popover API, and CSS carousels.
  • Example layouts are built with an unopinionated architecture: They provide complete flexibility, allowing you to easily adapt, modify, or integrate them into your stack. Each starter is a standalone HTML file that requires no build step.

Learn More About Web Expressive

Every starter layout is composed from Web Expressive design tokens and primitives. To customize or build new interfaces from scratch, refer to the comprehensive guides in the documentation:

  • Theming & Modes: Learn how to swap among 50+ light and dark color schemes, configure brand typefaces, and apply scoped island overrides.
  • Tokens Reference: Explore the complete CSS custom properties specification for color roles, 30 typescales, elevation levels, motion curves, spacing, and 35 abstract shapes.
  • Components Guide: Discover accessible action buttons, toggle controls, icon buttons, button groups, switches, and floating action buttons built on native HTML.
